# 🤖 AI-jobbanalys

Ett Python-projekt som analyserar vilka tekniker som efterfrågas i jobbannonser för AI-utvecklare.

## 🎯 Syfte

Syftet med projektet är att analysera jobbannonser och få en bättre förståelse för vilka tekniska kunskaper som är viktiga för en AI-utvecklare.

## 📊 Resultat

Analysen visar följande resultat:

- Python: 4

- SQL: 3

- AWS: 2

- Docker: 1

Python var den mest efterfrågade tekniken i de analyserade jobbannonserna.

## 🛠️ Tekniker och verktyg

- Python

- Jupyter Notebook

- Matplotlib

- Git

- GitHub

## 📈 Visualisering

Resultatet visualiseras med ett stapeldiagram i Matplotlib för att göra det enkelt att jämföra efterfrågan på de olika teknikerna.

## 🧠 Vad jag lärde mig

Genom projektet har jag tränat på att:

- arbeta med dictionaries i Python

- använda loops och summering

- analysera data

- skapa diagram med Matplotlib

- dokumentera ett projekt med Markdown

- använda Git och GitHub för versionshantering

## 🚀 Fortsatt utveckling

Nästa steg är att analysera fler jobbannonser och automatisera insamlingen av data för att få ett större och mer realistiskt underlag.


## 🔍 Metod

I projektet analyserade jag data från jobbannonser för AI-utvecklare för att undersöka vilka tekniker som efterfrågas. Datan strukturerades i Python och analyserades med hjälp av dictionaries och loopar. Resultatet visualiserades med Matplotlib för att göra det lättare att jämföra teknikerna.

Jag använde även ett AI-API för att analysera resultatet och få en kort sammanfattning av vilka tekniker som var mest och minst efterfrågade.

## 📊 Branschanalys – Mål 1

AI-utveckling är ett område där kunskaper inom programmering, data och AI är viktiga. I de jobbannonser som analyserades förekom Python, SQL, AWS och Docker.

I min analys var Python den mest efterfrågade tekniken. Resultatet visar att programmering i Python är en viktig kunskap för den som vill arbeta inom AI-utveckling.

Eftersom projektet analyserar ett litet antal jobbannonser går resultatet inte att använda för att beskriva hela arbetsmarknaden. Ett större antal annonser skulle ge ett mer tillförlitligt resultat.

## 🎓 Certifikat-koll – Mål 5

Inom AI och IT finns flera certifieringar som kan vara relevanta för arbetslivet. Exempel är certifieringar inom AWS, Microsoft Azure och andra molntjänster.

Utifrån min analys är Python en viktig kunskap att prioritera. Kunskaper inom SQL, AWS och Docker är också relevanta och kan kompletteras med certifieringar och vidare utbildning.

Certifieringar kan vara ett sätt att visa kunskaper inom ett specifikt område, men praktisk erfarenhet och egna projekt är också viktiga för att utvecklas som AI-utvecklare.

## 💭 Reflektion – Mål 8

Projektet har hjälpt mig att förstå hur Python kan användas för att strukturera och analysera data. Jag har också fått öva på att visualisera resultat med Matplotlib och använda ett AI-API för att analysera information.

En utmaning i projektet var att få de olika delarna att fungera tillsammans och att förstå hur data går från Python till analys och visualisering. Genom att testa koden steg för steg och rätta fel har jag fått en bättre förståelse för arbetsprocessen.

Om jag skulle utveckla projektet vidare skulle jag analysera fler jobbannonser och automatisera insamlingen av data. Det skulle ge ett större underlag och göra analysen mer tillförlitlig.
