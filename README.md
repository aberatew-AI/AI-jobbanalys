# AI-jobbanalys

## Om projektet
Detta projekt analyserar vilka tekniker som efterfrågas i jobbannonser för AI-utvecklare.

## Tekniker 
Projektet analyserar bland annat:
-Python
-SQL
-AWS
-Docker

## Resultat 
Analysen visar att Python är den mest efterfrågade tekniken i de analyserade jobbannonserna.
